# IoT Kids Books: student PDFs, part A (books 01A to 07C)

Smaller-edition student PDFs of the IoT Kids Books, served by GitHub Pages from the main branch (no GitHub Actions, no Git LFS; every file well under 100 MB). The QR edition PDFs carry invisible link annotations over each printed QR code (added without changing the printed pages). Links: https://ngcharithperera.github.io/iotclass-kidsbooks-pdf-a/<file>.pdf#page=N . Page layout of every student PDF: page 6 Story Finder, story i on page 5+2i (Storyboard) and 6+2i (Think and Talk). See manifest.json.
